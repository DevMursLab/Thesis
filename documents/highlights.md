# Highlights

(Elsevier-format highlights: 3-5 bullet points, max ~85 characters each,
submitted as a separate file alongside the manuscript.)

- Controlled tri-modal ablation isolates modality gains via one model class
- Multi-task PHQ-8 learning raises F1 from 0.607 to 0.629 across 5 seeds
- Test split (N=47) confirms generalization: F1=0.585, AUC=0.706
- Attention and fairness loss show honest non-significant results, not hype
- Three explainability methods agree: audio and brow-lowerer AU drive predictions
